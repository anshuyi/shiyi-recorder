## 麦克风根因与修改

设备编号随应用页面 origin 改变而变化。旧编号直接传入 exact 约束会失败；原界面可自行选择其他设备而录制仍用旧编号。原代码还允许麦克风失败后继续无声录制。

新实现用同一解析函数处理界面和录制。有效编号直接用；编号变化时只接受唯一名称匹配；缺失或同名歧义要求重新选择。新设置保存设备名称，显式 null 清除系统默认选择的旧编号，设置写入串行化。旧设置只有编号时不能可靠推断设备，首次需要重选。

开启麦克风时先连接并验证音轨。浏览器声音录制器收到首个非空数据块才进入录制状态；连接、权限、录音器、取消或超时失败会清理本轮启动。数据块只证明有编码数据，不保证里面有人声。

对浏览器音轨 ended、录音器错误/意外停止、持续无数据增加提示和停止保存；正常暂停与有数据的自然静音不触发异常停止。取消时释放音轨并解除旧数据事件，避免干扰下一次录制。
